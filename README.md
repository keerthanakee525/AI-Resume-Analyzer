🚀 AI Resume Analyzer & Skill Gap Detector

📌 Project Overview

AI Resume Analyzer is a Python-based web application developed using Streamlit.

It helps students and job seekers analyze their resumes, identify missing skills, and improve their job readiness.

✨ Features

- 📄 PDF Resume Upload
- 🎯 Target Job Role Selection
- 📊 Skill Match Percentage
- ✅ Matched Skills Detection
- ❌ Missing Skills Identification
- 📈 Interactive Skill Analysis Chart
- 📚 Learning Resources
- 💡 Career Recommendations
- 📥 Downloadable Analysis Report

🛠️ Technologies Used

- Python
- Streamlit
- PyPDF
- Plotly
- HTML & CSS

⚙️ How It Works

1. Enter your name.
2. Select your target job role.
3. Upload your resume in PDF format.
4. Click "Analyze My Resume".
5. View your skill match percentage.
6. Identify matched and missing skills.
7. Explore recommended learning resources.
8. Download your analysis report.
